# Security Policy

## Supported versions

| Task version | Supported |
| --- | --- |
| `CloudsmithCliSetupAndAuthenticate@2` | Yes |
| `CloudsmithCliSetupAndAuthenticate@1` | Maintenance fixes only |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately using GitHub's
[private vulnerability reporting](https://github.com/cloudsmith-io/cloudsmith-ado-integration/security/advisories/new)
(Security tab → "Report a vulnerability"), or email
[support@cloudsmith.io](mailto:support@cloudsmith.io).

You will receive a response as quickly as possible. Please include enough
detail to reproduce the issue, and allow time for a fix before any public
disclosure.
